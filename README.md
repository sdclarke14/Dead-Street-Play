# Dead Street - play

A free 2D pixel-art zombie shooter for the browser and iPhone.

- **7 missions** (zombies, vampires, witches, robots, raptors, mummies, aliens), 135 stages and 47 locations
- **28 guns**, 12 melee weapons (bat, katana, chainsaw...), 70 gun upgrade parts and 11 timed perks
- **5 playable species**, a Gauntlet mode and 86 cosmetic looks (hairstyles, fabrics, outfits)
- **Vehicles** from mystery boxes (war bike, monster truck, giant bullet), a 3-tier jetpack with homing missiles, explosive barrels and house raids
- **Save & Exit** on every run, saved on your device

**Play:** https://sdclarke14.github.io/Dead-Street-Play/ (or open `index.html` directly in a browser).
On iPhone: open the link in Safari, then Share > Add to Home Screen.

This repo holds only the finished game files. The source, art and build tools live in the Dead-Street-Zombie repo.
